# 📊 Agregador de Dados para Imposto de Renda no Excel

Este projeto consiste em uma ferramenta robusta e automatizada desenvolvida no Excel para centralizar, organizar e validar todas as informações essenciais necessárias para a Declaração Anual de Imposto de Renda (DIRPF). 

O objetivo principal é transformar o controle financeiro em uma experiência simples, mitigando erros de preenchimento por meio de automações nativas do Excel.

## 🚀 Funcionalidades do Projeto

- **Painel de Navegação (Menu Inicial):** Interface amigável com botões interativos (hiperlinks) para navegação rápida entre as abas e links externos úteis (como o portal da Receita Federal).
- **Validação de Dados Automatizada:** Uso de listas suspensas (Data Validation) baseadas em tabelas de apoio para evitar erros de digitação em categorias e códigos de rendimento/bens.
- **Segregação de Dados:** Abas organizadas por módulos específicos:
  - Rendimentos Tributáveis e Isentos
  - Despesas Dedutíveis (Saúde, Educação, Previdência)
  - Controle de Bens, Direitos e Ônus Reais
- **Fórmulas e Formatação Condicional:** Alertas visuais automáticos para campos obrigatórios em branco ou valores inconsistentes.

## 🛠️ Tecnologias Utilizadas

- **Microsoft Excel:** Construção das tabelas, inteligência lógica, validações e interface visual.
- **Markdown:** Estruturação desta documentação no GitHub.
